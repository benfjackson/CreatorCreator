## Archetype section recipes (consensus)

### B2B SaaS

```
Hero (H1 outcome + subhead + 1–2 CTAs + product visual)
→ Logo bar (#2–3)
→ Positioning / 3 pillars
→ Feature sections (2–4 deep dives with UI)
→ Social proof (testimonials)
→ Scale metric ("X teams")
→ Changelog or ship velocity (optional)
→ Final CTA band
```

### B2B services

```
Hero (outcome H1 + credibility line + demo/contact CTA)
→ Logo bar
→ Problem / stakes OR case study with metrics
→ Service modules or methodology
→ Industry/persona segmentation
→ Testimonials
→ FAQ or objection handling (productised services)
→ Demo/contact form
```

### Mission-led

```
Hero (mission H1 + theory of change one-liner + soft CTA)
→ Trust logos / funders / partners
→ Programmes or pillars (3-up)
→ Impact metrics
→ Resources / frameworks / stories
→ Dual audience split (if applicable)
→ Newsletter / donate / partner CTA
→ News/events (optional)
```
